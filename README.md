# Task Manager

A full-stack Task Manager application built with Spring Boot, React, MySQL, REST API, and Docker.

## Features

- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- RESTful API
- MySQL database
- React frontend
- Docker Compose setup

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Data JPA
- REST API
- Maven

### Frontend
- React
- JavaScript
- Vite
- CSS

### Database
- MySQL

### DevOps
- Docker
- Docker Compose
- Nginx
